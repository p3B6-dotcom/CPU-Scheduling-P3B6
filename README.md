# محاكي جدولة المعالج — المجموعة P3B6

برنامج مكتوب بلغة Python لمحاكاة خوارزميتي جدولة المعالج:

- **FCFS** — أسبقية الوصول أولاً.
- **SJF** — أقصر مهمة أولاً، بصورة غير مقتطعة.

يقرأ البرنامج بيانات المجموعة من الملف `input.txt`، وينشئ مخططات جانت، ويحسب أزمنة الانتظار والدوران والاستجابة، ويقارن متوسطات النتائج. كما يمكنه تصدير جداول النتائج إلى ملفات CSV.

## متطلبات التشغيل

- Python بإصدار 3.9 أو أحدث.
- لا يحتاج البرنامج إلى مكتبات خارجية.

## ملفات المشروع

- `main.py` — الكود الأساسي لمحاكي الجدولة.
- `input.txt` — بيانات الإدخال الخاصة بالمجموعة P3B6.
- `test_main.py` — الاختبارات الآلية.
- `REPORT_TEMPLATE.md` — تقرير المشروع.

## تشغيل البرنامج

ضعي `input.txt` في المجلد نفسه الذي يحتوي على `main.py`، ثم نفّذي الأمر:

```bash
python main.py
```

لاختيار ملف إدخال آخر:

```bash
python main.py --input path/to/input.txt
```

لتصدير جداول النتائج إلى ملفات CSV:

```bash
python main.py --export
```

## تنسيق ملف الإدخال

يحتوي كل سطر بيانات على أربعة حقول بالترتيب الآتي:

```text
PID ARRIVAL BURST PRIORITY
```

يتجاهل البرنامج الأسطر الفارغة والتعليقات التي تبدأ بالرمز `#`. كما يتحقق من عدد الحقول، والقيم الصحيحة، وعدم تكرار معرّفات العمليات، وعدم سلبية زمن الوصول، وأن يكون زمن التنفيذ أكبر من الصفر.

## قواعد الجدولة

### FCFS

تُجدول العمليات حسب زمن الوصول تصاعدياً. وعند تساوي زمن الوصول، يُحافَظ على ترتيبها في ملف الإدخال. الخوارزمية غير مقتطعة.

### SJF غير المقتطعة

عند توفر المعالج، يختار البرنامج أقصر عملية من العمليات التي وصلت بالفعل. وعند تساوي زمن التنفيذ، يُختار الأسبق وصولاً، ثم الأسبق في ترتيب ملف الإدخال. إذا لم تكن هناك عملية جاهزة، يُحتسب وقت خمول المعالج حتى وصول العملية التالية.

## تعريف المقاييس

- `Waiting Time = Start Time - Arrival Time`
- `Turnaround Time = Finish Time - Arrival Time`
- `Response Time = First Start Time - Arrival Time`

## ملاحظة حول الأولوية

يحتفظ البرنامج بحقل الأولوية الرابع لأنه جزء من تنسيق ملف بيانات المجموعة، ويظهر في ملفات CSV المصدّرة. لكنه لا يُستخدم في خوارزميتي FCFS وSJF المطبقتين هنا؛ إذ لا تمثل أي منهما خوارزمية جدولة بالأولوية.

## قابلية إعادة النتائج

تستخدم المحاكاة قواعد ثابتة لكسر التعادل، لذلك ينتج عن ملف الإدخال نفسه ترتيب ونتائج متماثلة في كل تشغيل.
